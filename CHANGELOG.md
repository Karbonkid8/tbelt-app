# Changelog

All notable user-facing changes to FieldOps are recorded here.

## [0.1.1] - 2026-08-30

### Fixed

- All three primary work tabs remain visible and tappable on mobile screens.

## [0.1.0] - 2026-08-30

### Added

- FieldOps worksite shell with Site Code and administrator sign-in
- Admin location creation, activation, Site Code rotation, and permanent removal
- Frac and Pump Down chemical container inventories
- ISO and Poly 330 container types with strap entries and optional notes
- Container strap history, plotted trend view, and operator audit details
- T-Belt RunDown with ten stations, Start marker, compact view, and SMS report handoff
- Requisition form foundation
- Installable PWA support and refresh-safe session restoration

### Changed

- Chemical inventory is responsive: desktop table on larger screens and labeled container cards on phones.
- App assets update network-first so operators receive the current release after refresh.
